# 🕹️ MD. Sajedul Hoque - Personal Arcade & Recreation Showcase

Welcome to the GitHub repository for my personal website's recreation and entertainment showcase! This project is a tribute to childhood nostalgia, featuring custom-built, retro-inspired web arcade games seamlessly integrated next to my personal portfolio profile[cite: 1].

🌐 **Live Website:** [jonotarbazar.netlify.app](https://jonotarbazar.netlify.app)[cite: 1]

---

## 🌟 Featured Games & Mini-Apps

### 🍎 1. Apple DX-Strike
Inspired by the traditional childhood DX-Ball game[cite: 1], this modernized arcade game features:
* **Power-Up System:** Random capsules dropped from broken apples (Extra Life ❤️, Multi-Ball ⚽, and Expanded Paddle 📏).
* **Neon Particle Effects:** Vibrant spark bursts whenever the ball collides with walls, paddles, or fruits.
* **Smooth Controls:** Fully optimized for desktop mouse movement, keyboards, and responsive mobile touch gestures.

### 🏎️ 2. Turbo Car Racing
A top-down arcade dodging game featuring:
* **Realistic Procedural Sprites:** Clean, custom-rendered top-down graphics for both your sports car and incoming traffic.
* **Progressive Difficulty:** Roads accelerate dynamically as your score increases.
* **Instant Auto-Restart:** Seamless game-over transitions without browser popup blockages.

---

## 🚀 Key Technical Features

* **Interactive Particle Starfield:** A dynamic background canvas featuring drifting stars that connect with glowing lines as your mouse moves.
* **Dual Game Switcher:** An integrated arcade mode switcher allowing visitors to instantly toggle between games right on the screen.
* **Fully Responsive Design:** Flexbox layout and fluid scaling designed to look pristine on desktop monitors, tablets, and smartphones.
* **Zero Dependencies:** Built entirely with pure **HTML5 Canvas**, **CSS3 (Glassmorphism & Cyberpunk Neon UI)**, and vanilla **JavaScript**.
